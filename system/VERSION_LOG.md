# 系统版本日志

## v1.0.0

### 版本概述
- 初始版本，完成耳机评论情感分析系统的基础代码搭建。
- 系统实现遵循既定设计思路：数据导入、文本预处理、情感分类、模型对比、细粒度分析、痛点挖掘、结果展示与导出。

### 新增内容
- 新增多格式数据导入能力，支持 CSV / Excel / JSON 评论数据。
- 新增文本清洗、分词、停用词过滤、标准化等预处理能力。
- 新增 SVM、TextCNN、BERT 三类模型接口与统一训练/预测流程。
- 新增模型评估与对比输出，支持 accuracy、precision、recall、F1 等指标。
- 新增基于属性关键词的细粒度情感分析。
- 新增负面评论痛点挖掘，包括高频词统计和聚类摘要。
- 新增结果可视化与 CSV / JSON 导出能力。
